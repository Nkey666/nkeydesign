## Что сделано (управляется кодом)

### Structured Data — 92/100
- Единый JSON-LD `@graph`, связанный по `@id`: `Person`, `ProfessionalService`, `WebSite`, `FAQPage`, `OfferCatalog` (5 услуг).
- `FAQPage` с 5 Q&A — главный источник цитат для AI Overviews и ChatGPT.
- `Person.knowsAbout` + `sameAs` — сигнал сущности для ИИ.
- `priceRange`, `areaServed` (Москва, СПб, РФ), `contactPoint`.

### AI Citability — 85/100
- robots.txt явно пускает GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended, CCBot, YandexBot.
- `llms.txt` переписан: услуги с ценами, процесс, реальные кейсы, FAQ дословно, контакты.
- FAQ-блоки = готовые «ответы» для нейропоиска.

### Technical Foundations — 88/100
- Next.js SSR: весь контент в HTML без JS (ИИ-краулеры видят всё).
- Один `<h1>`, `lang="ru"`, `viewport`, `canonical`, sitemap.xml, robots с `Host` для Яндекса.

### Platform Optimization — 80/100
- Google AI Overviews: FAQ + schema.
- ChatGPT / Perplexity: llms.txt + доступ + цитируемые Q&A.
- Gemini: Google-Extended разрешён.

## Слабые места (код НЕ чинит — нужны действия вне сайта)

### Brand Authority — 25/100 (главный потолок ранжирования)
ИИ и Яндекс/Google решают, кому доверять, по упоминаниям вне сайта. Сейчас их ноль (новый домен).
- `sameAs` = только Telegram. Добавь реальные: GitHub, VK, Behance/Dprofile, профиль на Хабр/Профи.ру.
- Получи упоминания: ответы на Хабр Q&A, кейсы на vc.ru, отзывы клиентов, репозитории на GitHub.
- Корреляция «упоминания vs ссылки» для ИИ — в 3 раза сильнее в пользу упоминаний.

### Content E-E-A-T — 55/100
- Автор анонимный («Никита», «студент московского вуза») — слабый сигнал доверия. Реальное имя + конкретика (стек, годы опыта, ссылки на живые проекты) поднимут балл.
- Нет дат, авторства, оригинальных данных (цифры, замеры скорости кейсов).

## План действий по приоритету

1. **Купить и задеплоить домен `nkeydesign.ru`** (HTTPS) — без живого сайта ничего не индексируется.
2. **Яндекс.Вебмастер + Google Search Console** — подтвердить права (плейсхолдеры в `metadata.verification` уже готовы), залить sitemap, ускорить индексацию.
3. **Заполнить `sameAs`** реальными профилями (GitHub/VK/Behance) в `lib/seo.ts`.
4. **Добавить реальное имя/фамилию и факты** в «О специалисте» — E-E-A-T.
5. **Набрать упоминания** вне сайта (vc.ru, Хабр, GitHub, отзывы) — это снимает потолок Brand Authority.
6. После деплоя: `/geo audit https://nkeydesign.ru` для автоматического прогона и `/geo brands` для отслеживания упоминаний.
